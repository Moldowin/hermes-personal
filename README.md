# Hermes Personal

Public informational homepage and privacy notice for a personal Google Workspace integration.

- Homepage: https://moldowin.github.io/hermes-personal/
- Privacy: https://moldowin.github.io/hermes-personal/privacy.html

Static HTML only. No OAuth credentials, Google content, sign-in endpoint, analytics, or external scripts belong in this repository. GitHub Pages publishes the root of `main`.

Publishing this site does not itself change Google OAuth publishing status. Review model-provider data controls before sending Google data for model inference.
