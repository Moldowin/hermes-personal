Hermes Personal

A privately operated Google Workspace integration for the operator’s personal use with Hermes Agent. It is not a public sign-up service.

What it does

After the operator grants Google OAuth consent, the integration can search and summarize Gmail, manage email labels and send approved messages, review or manage Calendar events, find and manage Drive files, read or update Google Sheets and Docs, and look up Contacts.

Google permissions control access. Sending messages, modifying events, and changing or sharing files require the operator’s approval; publishing this informational website does not grant anyone access to the operator’s Google account.

How it works

Hermes runs on the operator’s own devices. When the operator requests assistance, relevant Google data may be processed by the language-model provider selected in Hermes and appear in private chat history or configured outputs. This is not a promise that all processing remains on-device.

This public GitHub Pages site contains only an application description and privacy notice. It contains no Google credentials, mailbox content, contacts, calendar events, or Drive documents, and provides no Google sign-in form.

Privacy and control

Read the privacy policy for data access, processing, storage, deletion, and revocation details. Access can be revoked from Google Account connections.

Contact

For non-sensitive questions, contact the operator through the project’s GitHub issues. Issues are public: do not post passwords, tokens, personal Google data, or account-recovery information.
